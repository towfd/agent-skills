TOPIC: 一批 PR 驗完不合併

### 疊著的自動駕駛

跑 Autopilot-full 劇本，但不要合併。

1. **用「停在已驗證」取代第 5 步。** 每個 PR 都在它目前的 head 上驗證過、而且是綠燈時就停，然後把這些 PR 交給操作者。交接之後，沒有操作者的放行，誰都不准推送。每次 loop 觸發的提示詞都要寫出這個檔，這樣每次觸發都看得到「不合併」這條規則。
2. **只有當一個 PR 是建立在另一個 PR 之上時，才把它疊上去。** 這是第 3 步唯一的例外。照 `playbooks/opening-a-pr.md`，把這個 PR 的基準設成另一個 PR 的分支，取代主幹。取代第 2 步的 rebase 到主幹，每個 PR 改成 rebase 到它父 PR 的分支上，而這一疊的根 rebase 到主幹上。下層的 PR 有了新的 head，就要把它上面的 PR 重新疊一次，而重新疊過之後 `git patch-id` 沒變的 PR，保留它的判定。

**回覆：** 列出每個 PR 和它的判定，取代「哪些合併了」。
