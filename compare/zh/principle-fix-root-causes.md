# 修根本原因

修的是錯誤本身，不是它浮現出來的地方。根本原因是系統第一次做了不該做的事，或沒有處理一個應該處理的狀態的那個地方。

- 先重現。一直問「為什麼」，直到答案是程式裡一個錯誤的決定。卡住的時候，加上觀測點，讀實際的狀態。
- 問觸發症狀的那個狀態是不是正當的。如果是，就在程式壞掉的地方處理它。如果它根本不該存在，在那裡加檢查會把 bug 藏起來，所以要找出是什麼產生了它。防護、重試、吞掉錯誤、把數值硬夾在範圍內、丟掉狀態，是藏住 bug 的常見方式。
- 修整個模式，不是修單一個案。找出每一個有同樣錯誤的地方。
- 如果那個關鍵的事實是挖得很深才找到的，就提出一個便宜、一直開著的訊號，讓它本來在第一眼就能被看到。
