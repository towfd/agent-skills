# 型別系統紀律

讓編譯器拒絕不可能的狀態、搭配錯誤的基本型別，以及沒處理到的變體。

- **替有語意的基本型別加上標記。** 如果兩個參數共用同一個基本型別、但意思不同，就給它們各自的型別。在建立的時候驗證一次。
- **外部資料在解析之前都是沒有型別的。** JSON、RPC 傳來的內容、CLI 參數、設定、環境變數和資料庫的資料列，都要在邊界經過一個解析函式，由它回傳有型別的模型。
- **從具權威性的 schema 推導型別。** 當某個形狀歸一個 schema 檔管時，從它推導出型別，不要自己手寫一個平行的。

TypeScript 的語法，請看 **typescript-best-practices** skill。
