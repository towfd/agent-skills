pstack 原文對照

左邊是原檔的原文，由程式直接從檔案帶進來，一個字都沒改。右邊是照原文逐段翻的中文，沒有加我的意見。目前六十七個檔：前八個是第一批，接著三個是給 agent 看的入口、工人守則和開場提示，再來是二十份劇本、二十一條原則、十二個 skill、兩份 agent 設定，最後一份是原作者寫的 Claude Code 對照表。

來源 github.com/cursor/plugins 的 pstack/ 版本 7a58391（2026-11-21） 開場提示來自移植版 github.com/michael-denyer/pstack-claude，版本 81603a4 MIT License，Copyright (c) 2026 Lauren Tan

最右邊的數字是原文的英文字數。

幾個沒翻的詞

agent
做事的 AI 對話
subagent
被主對話派出去做一小段事的小助手
skill
一份寫給 agent 的做事說明
commit
存進版本紀錄的一筆存檔
wip:
「還沒做完」的存檔標記
PR
一包送審的程式修改
diff
修改前後的差異
log
程式跑的時候留下的紀錄

第八個是指南第 2 章的其中一節，不是整章。入口那份放的是原版；Claude Code 移植版的同一份有 64 行不同，多半是把 Cursor 專有的工具名稱和模型名稱換掉。

原文裡的 **、`、--- 是 Markdown 的格式記號，照原樣留著。
